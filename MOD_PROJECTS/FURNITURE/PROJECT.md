# FURNITURE 작업 기준

## 확정 사항

- 심홍 고급 식탁은 3×2이며 양쪽 긴 변 중앙에 한 자리씩 둔다.
- 연결한 침대의 주인 한 명 또는 두 명만 사용한다. 일반 침대와 더블 침대를 지원한다.
- 침대 주인 교체·연결 해제에 따라 사용 권한이 바뀌며 연결은 저장 후에도 유지한다.
- 심홍 고급 식탁 의자의 게임 북향은 아틀라스의 정면 이미지다. 북향 발끝을 선택 칸 하단에 맞춘다.
- 선체벽을 쓰는 심홍 벽형 냉장고·벽형 약품장은 SOS2_ADDON 소속이다. 일반 냉장고는 이 프로젝트 소속이다.

## 현재 작업

- 식탁 양쪽 자리 선택·동시 예약·두 주인 제한·저장/재로드를 검증한 뒤 적용한다.
- 식탁 의자 하향 조정과 북향 추가 보정을 함께 검증한다.
- 현재 단계: 0.12.33.0 격리 게임 검사와 합성 저장/재로드를 통과하여 적용본에 반영했다. 기존 게임과 격리 검사 게임은 모두 종료되어 있으며, 다음 적용본 실행부터 반영된다.

소스: `Source/Main/CrimsonCommanderDining.cs`와 `Content/1.6/Defs/CrimsonPremiumSeating.xml`.
